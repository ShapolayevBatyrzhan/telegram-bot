# telegram-bot
=======
# Бот "Альянс женщин предпринимателей"

Telegram-бот на Python для регистрации участниц, подачи заявлений на вступление, администрирования заявок и генерации PDF-свидетельства после одобрения.

## Возможности

- Главное меню минимум с 6 кнопками: `Вход`, `Регистрация`, `Новости`, `Администратор`, `Заявление на вступление`, `Мой статус`.
- Регистрация через кнопку Telegram `Поделиться номером`, без ручного ввода телефона.
- Привязка номера телефона к Telegram ID.
- Пошаговый сбор ФИО, ИИН и вида деятельности.
- Подача заявления: подтверждение личности, вид деятельности, название компании, предпросмотр, редактирование или подача.
- Номер заявления после успешной подачи.
- Уведомление администраторам о новой заявке.
- Админ-панель со списком новых заявок.
- Одобрение с комментарием или отказ с причиной.
- Генерация PDF-свидетельства о вступлении после одобрения.

## Установка

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
```

Откройте `.env` и заполните:

```env
BOT_TOKEN=токен_бота_от_BotFather
ADMIN_IDS=telegram_id_админа
```

Telegram ID можно узнать через специальных ботов вроде `@userinfobot`.

## Запуск

```powershell
python bot.py
```

## Как работает роль администратора

Кнопка `Администратор` открывает админ-панель только тем пользователям, чей Telegram ID указан в `ADMIN_IDS`. Остальным бот покажет отказ в доступе.

Когда пользователь подает заявление, все администраторы получают уведомление. Администратор может открыть заявку, нажать `Одобрить` или `Отказать`, затем бот попросит комментарий или причину отказа.

После одобрения бот создает PDF-файл в папке `certificates` и отправляет его пользователю.
